# Atlanta Food Finder & Spotify Stats

**Personal Projects**
Aug. 2024 – Oct. 2024

**Stack:** Python, Django REST Framework, Next.js, Tailwind CSS, Google Places API, Spotify API, Gemini API

I built two full-stack web applications back to back: a restaurant discovery tool for the Atlanta area and a Spotify listening statistics app, both sharing a common architecture of a Django REST backend paired with a Next.js and Tailwind CSS frontend.

Atlanta Food Finder integrates the Google Places API to surface restaurant recommendations, while the Spotify Stats app pulls listening data through the Spotify API. Both apps use the Gemini API for AI-assisted features layered on top of the raw data. I optimized query handling on the backend to keep real-time data retrieval responsive under the constraints of third-party API rate limits.

I led a five-person team as Scrum Master, running sprint planning and stand-ups under a hybrid Kanban/Extreme Programming (XP) process, coordinating scope, unblocking teammates, and keeping both apps shipping on parallel timelines.
