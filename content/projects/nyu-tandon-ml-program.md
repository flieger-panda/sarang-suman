# NYU Tandon Machine Learning Program

## Overview

**Participant**
July 2023 – Aug. 2023

**Stack:** TensorFlow, Scikit-Learn, numpy

## What I Did

I completed an intensive machine learning program through NYU Tandon, covering applied ML fundamentals from classical models through deep learning and computer vision.

I trained and tuned a range of models, including random forests, convolutional neural networks (CNNs), and YOLOv3 for object detection, working through the full pipeline from data preprocessing to model evaluation. I achieved 95% test accuracy, the top score in a cohort of more than 50 students, and improved detection accuracy by 20% through systematic hyperparameter tuning and batched preprocessing.

The program built a practical foundation in both traditional and deep learning approaches, with particular depth in the preprocessing and tuning work that often separates a functional model from a well-performing one.
